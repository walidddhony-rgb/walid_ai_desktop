# Walid AI Desktop v7 — Diff Review + Context Compaction

## New in v7
- **Diff Review**: When the agent creates or edits files, you see a visual diff before changes are applied.
- **Context Compaction**: Long conversations are automatically summarized to stay within token limits.
- **Token Counter**: Real-time context size display in the status bar.
- **edit_file tool**: New tool for surgical file edits with old_text/new_text replacement.
- **Auto-apply per file**: Approve once and the same file auto-applies for the rest of the session.

## Diff Review
- New files: Shows full content preview before creating.
- Modified files: Shows unified diff (green=additions, red=deletions).
- Reject: Cancels the file change.
- Auto-apply checkbox: Skip review for this file in this session.

## Context Compaction
- Monitors conversation token count automatically.
- When approaching 24,000 tokens, summarizes older messages.
- Keeps the 4 most recent messages intact.
- Summary is generated by the local LLM in Arabic.
- Compaction event appears in the task log.

## Windows run
```powershell
pip install -r requirements.txt
ollama serve
```
