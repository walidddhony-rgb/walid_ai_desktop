Walid AI Desktop v10.1.0
========================

A local-first desktop AI agent built with **PyQt6** and **Ollama**: voice, document understanding, a RAG knowledge base, web search, and safe file/code tools with visual diff review — all running on your machine.

Highlights (v8 – v10)
---------------------

*   • **Subagents** (`core/subagent.py`): delegate focused subtasks to separate agent instances
*   • **Hooks** (`core/hooks.py`): extension points in the agent lifecycle
*   • **Skills** (`core/skills.py`): packaged, reusable agent capabilities
*   • **AGENTS.md support** (`core/agents_md.py`): project-level agent instructions
*   • **Sandboxed code execution** (`core/sandbox.py`, `core/code_executor.py`)
*   • **Sessions & profiles** (`core/session.py`, `core/profiles.py`)
*   • **Tool registry** (`tools/registry.py`) with a modular tool suite: file tools, workspace tools, execution tool, memory tools, learning tools, and a system agent
*   • **RAG knowledge base**: document ingestion (`knowledge/ingestor.py`) with background indexing (`knowledge/index_worker.py`), backed by SQLite + embeddings (`db/`)
*   • **Web search** (`search/engine.py`) via DuckDuckGo
*   • **Voice** (`voice/stt_engine.py`, `voice/tts_engine.py`): Whisper / faster-whisper for STT, pyttsx3 / edge-tts for TTS
*   • **UI**: themes, dialogs, and rich message rendering for PyQt6

Core safety features (v7)
-------------------------

### Diff Review

*   •  
    New files: shows full content preview before creating.
*   •  
    Modified files: shows unified diff (green = additions, red = deletions).
*   •  
    Reject: cancels the file change.
*   •  
    Auto-apply checkbox: skip review for this file in this session.

### Context Compaction

*   •  
    Monitors conversation token count automatically.
*   •  
    When approaching 24,000 tokens, summarizes older messages.
*   •  
    Keeps the 4 most recent messages intact.
*   •  
    Summary is generated by the local LLM in Arabic.
*   •  
    Compaction event appears in the task log.

Also in v7: a real-time **token counter** in the status bar, the `edit_file` tool for surgical `old_text`/`new_text` edits, and per-file **auto-apply**.

